# 测试用例：周报月报写作

## Skill

`weekly-monthly-report-writer`

## 测试目标

检查 Skill 是否能把零散工作事项整理成有价值表达的周报，而不是流水账。

## 测试输入

```text
请使用 weekly-monthly-report-writer 帮我写本周周报。

角色：
数据分析师。

读者：
直属 Leader。

周期：
2026-05-20 到 2026-05-26。

本周事项：
- 梳理新用户 7 日首购转化率口径
- 和产品确认 7 天窗口、退款、渠道归因还有争议
- 用 mock 数据跑了首购转化漏斗测试
- 发现一版预期数据写错，已经通过脚本修正
- 写了 SQL Review 测试用例，发现 left join 右表 where 过滤风险
- 补了 PPT 汇报 Skill 的测试用例
- 还没补齐所有 Skill 的真实 Agent 输出评测

下周计划：
- 补齐剩余 Skill 的实际输出评测
- 整理一篇对外介绍文章
- 准备给会员演示的案例

希望输出：
请写成一份简洁周报，包括本周重点、关键进展、风险阻塞、下周计划。
```

## 通过标准

- 不得按事项列表机械复述。
- 必须把工作归纳成 2-4 条主线。
- 必须体现“测试发现问题并修正”的价值。
- 必须写出风险：真实 Agent 输出评测还没完全覆盖。
- 必须给出清楚的下周计划。
