# 测试用例：表设计

## Skill

`table-design-advisor`

## 测试目标

检查 Skill 是否能基于增长分析场景设计一张可用于渠道看板的 ADS 汇总表。

## 测试输入

```text
请使用 table-design-advisor 设计一张渠道新用户首购转化汇总表。

业务场景：
某电商平台渠道投放看板，需要每天查看不同渠道、设备的新用户注册、首购和转化表现。

下游使用：
- 渠道投放看板
- 新用户转化日报
- 投放负责人每周复盘

核心指标：
- 新注册用户数
- 7 日首购用户数
- 7 日首购转化率

查询维度：
- dt
- channel_id
- device_type
- campaign_id

上游表：
- dwd_user_register_d，粒度：一行一个注册用户
- dwd_order_detail_d，粒度：一行一个订单

执行环境：
Hive / Spark，T+1 更新。

希望输出：
请给出表定位、表粒度、字段设计、分区、更新策略、质量规则建议和待确认问题。
```

## 通过标准

- 必须先明确表粒度。
- 应建议 ADS 日粒度汇总表。
- 应指出 7 日首购指标存在延迟回看问题。
- 应设计注册数、首购数、转化率等核心字段。
- 应提出渠道归因、退款处理和 7 日窗口待确认。
