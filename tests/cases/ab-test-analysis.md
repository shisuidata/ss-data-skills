# 测试用例：A/B 实验分析

## Skill

`ab-test-analysis`

## 测试目标

检查 Skill 是否能同时看实验设计、核心指标、护栏指标和业务决策，而不是只看转化率提升。

## 测试输入

```text
请使用 ab-test-analysis 解读下面的实验。

实验目标：
判断新版移动端支付页是否能提高支付成功率。

实验假设：
减少支付页加载和表单步骤，可以提升提交订单后的支付成功率。

对照组：
旧版支付页，5000 个提交订单用户，支付成功 350。

实验组：
新版支付页，5020 个提交订单用户，支付成功 390。

实验周期：
2026-05-01 到 2026-05-07。

护栏指标：
- 支付页错误率
- 页面加载时间
- 客服投诉
- 退款率

已知问题：
目前只拿到了核心转化数据，护栏指标还没汇总。

希望输出：
请判断这个实验是否可以全量，并说明还需要补哪些数据。
```

## 通过标准

- 必须计算或指出实验组支付成功率高于对照组。
- 必须强调没有护栏指标不能直接全量。
- 必须检查实验周期、样本量、分流随机性和是否提前停止。
- 必须给出继续观察、小流量扩大或补数据的决策建议。
- 不得只凭转化率提升就建议全量。
