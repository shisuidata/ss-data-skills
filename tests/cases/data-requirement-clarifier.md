# 测试用例：需求澄清

## Skill

`data-requirement-clarifier`

## 测试目标

检查 Skill 是否能把模糊的“转化下降”需求整理成可执行的数据分析任务。

## 测试输入

```text
请使用 data-requirement-clarifier 帮我澄清这个需求。

业务背景：
某电商平台在 2026 年 5 月发现新用户首购转化率下降。业务团队希望判断下降是否真实存在，并定位主要原因。

原始需求：
最近新用户购买转化下降了，老板想知道为什么。希望能按渠道和设备拆一下，本周五前给结论。

已知信息：
- 分析周期：2026-05-01 到 2026-05-14
- 对比周期：2026-04-17 到 2026-04-30
- 涉及数据表：
  - dwd_user_register_d
  - dwd_user_event_d
  - dwd_order_detail_d
- 需要关注渠道 A 和移动端

希望输出：
请整理成可执行的数据分析任务，包括指标、维度、数据范围、开发拆解和待确认问题。
```

## 通过标准

- 能识别任务类型是专题分析 + 异常排查。
- 能明确核心指标是新用户 7 日首购转化率。
- 能列出渠道、设备、漏斗步骤等分析维度。
- 能提出 7 日窗口、退款、渠道归因、支付时间等待确认问题。
- 不直接编造 SQL 结果。
