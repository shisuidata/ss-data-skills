# 测试用例：指标口径审查

## Skill

`metric-definition-reviewer`

## 测试目标

检查 Skill 是否能审查“新用户 7 日首购转化率”的口径边界，尤其是时间窗口、退款、去重和渠道归因。

## 测试输入

```text
请使用 metric-definition-reviewer 审查这个指标。

指标名称：
新用户 7 日首购转化率

业务场景：
用于某电商平台渠道投放看板，判断不同渠道的新用户质量。

当前口径：
注册后 7 天内完成支付的新用户数 / 新注册用户数。

已知上下文：
- 新用户来自 dwd_user_register_d
- 支付订单来自 dwd_order_detail_d
- 注册表字段：user_id, register_time, channel_id, device_type, campaign_id
- 订单表字段：user_id, pay_time, pay_status, refund_status
- 当前存在争议：
  - 7 天按 7 个自然日还是滚动 168 小时
  - 全额退款订单是否算转化
  - 渠道归因用注册来源还是首触来源
  - 测试账号和内部账号是否排除

希望输出：
请给出推荐口径、风险点、边界条件和待确认问题。
```

## 通过标准

- 必须指出当前口径方向可用但边界不足。
- 必须拆清分子、分母、时间窗口、去重规则。
- 必须提出退款订单的主口径和净转化口径处理方式。
- 必须提出渠道归因和测试账号排除问题。
- 不得自行假设 7 天窗口、退款规则或渠道归因已经确定。
