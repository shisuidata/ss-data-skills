# 电商行业上下文

适用于电商、零售、交易平台、本地生活交易等业务。

## 核心业务对象

- 用户：新用户、老用户、会员、游客、买家、复购用户
- 流量：渠道、活动、广告、搜索、推荐、自然流量
- 商品：SPU、SKU、类目、品牌、价格带、库存、上下架状态
- 交易：购物车、下单、支付、退款、取消、履约、售后
- 商家/供给：店铺、供应商、仓库、配送、服务能力

## 常见核心指标

| 指标 | 常见含义 | 常见拆解 |
| --- | --- | --- |
| GMV | 支付或下单交易额，需明确是否扣退款 | 流量 * 转化率 * 客单价 |
| 支付订单数 | 支付成功订单数量 | 渠道、端、类目、价格带 |
| 支付用户数 | 发生支付的去重用户数 | 新老用户、会员等级、渠道 |
| 客单价 | GMV / 支付订单数或 GMV / 支付用户数 | 商品结构、满减、价格带 |
| 支付转化率 | 支付用户数 / 访问用户数或支付订单数 / 下单用户数 | 漏斗步骤、端、渠道 |
| 复购率 | 某周期内再次购买用户占比 | 新客 Cohort、类目、会员 |
| 退款率 | 退款金额或退款订单占比 | 类目、商家、履约、售后原因 |

## 高频分析场景

- GMV 下降：拆流量、转化率、客单价、退款、商品结构
- 转化下降：拆曝光、详情页、加购、下单、支付、风控、性能
- 渠道质量变化：拆新客占比、获客成本、首购率、复购率、退款率
- 活动复盘：拆活动流量、商品池、券成本、转化提升、毛利影响
- 商品/类目异常：拆库存、价格、上下架、竞争、配送、售后
- 退款上升：拆类目、商家、批次、履约时长、售后原因

## 常见维度

- 时间：小时、日、周、活动期、预热期、爆发期、返场期
- 用户：新老、会员等级、RFM、渠道来源、地域、设备
- 流量：渠道、投放计划、活动、搜索词、推荐场景
- 商品：类目、品牌、价格带、SKU、库存状态、是否活动商品
- 交易：支付方式、订单类型、优惠类型、配送方式、退款原因

## 常见数据风险

- GMV 是下单口径还是支付口径，是否扣退款
- 订单表一单多商品导致重复计算订单数或用户数
- 支付、退款、履约状态变更未同步到指标口径
- 活动跨天、跨时区或预售订单影响统计窗口
- 渠道归因窗口不一致导致渠道效果不可比
- 商品类目历史变更导致趋势断点

## 适合配合的 Skill

- `dashboard-reviewer`：审查经营看板、渠道看板、商品看板
- `business-root-cause-analysis`：分析 GMV、转化、退款、复购异常
- `funnel-analysis`：分析访问到支付的转化链路
- `retention-cohort-analysis`：分析新客复购和会员留存
- `data-incident-postmortem-writer`：复盘订单、支付、退款数据事故
