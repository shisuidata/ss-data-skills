# 内容社区行业上下文

适用于内容平台、社区产品、UGC 平台、创作者平台、知识社区、短视频或图文内容产品。

## 核心业务对象

- 用户：浏览用户、互动用户、发布用户、核心用户、回访用户
- 创作者：新创作者、活跃创作者、头部创作者、签约创作者
- 内容：文章、视频、笔记、帖子、评论、话题、合集
- 分发：推荐、关注、搜索、话题、活动、站外分享
- 互动：点击、阅读、播放、点赞、收藏、评论、转发、关注
- 治理：审核、下架、低质内容、违规、举报

## 常见核心指标

| 指标 | 常见含义 | 常见拆解 |
| --- | --- | --- |
| DAU/MAU | 日活/月活用户数 | 新老、渠道、端、内容偏好 |
| 留存率 | 用户在后续周期回访占比 | 注册 Cohort、行为 Cohort |
| 内容发布率 | 用户或创作者发布内容占比 | 新老创作者、内容类型 |
| 人均消费时长 | 用户消费内容的平均时长 | 推荐、关注、搜索、内容类型 |
| 曝光点击率 | 内容曝光后被点击或播放的比例 | 位置、算法版本、标题封面 |
| 互动率 | 点赞、评论、收藏、转发等互动占比 | 内容类型、用户分层 |
| 创作者留存 | 创作者持续发布或获得反馈的比例 | 首发体验、反馈、流量分配 |

## 高频分析场景

- DAU 下降：拆新增、回访、召回、渠道、内容供给、产品故障
- 留存下降：拆新用户首日体验、内容匹配、互动反馈、消息召回
- 内容供给不足：拆创作者发布率、审核通过率、首发成功率、反馈强度
- CTR 下降：拆推荐流、搜索、话题页、标题封面、算法版本
- 互动下降：拆内容质量、用户结构、评论氛围、激励机制
- 创作者流失：拆曝光、互动反馈、收益、审核、工具体验

## 常见维度

- 用户：新老、活跃层级、兴趣标签、渠道、设备、地区
- 内容：类型、主题、长度、质量分、发布时间、审核状态
- 创作者：等级、粉丝量、历史发布频率、签约状态、垂类
- 分发：推荐、关注、搜索、话题、活动、站外分享
- 行为：曝光、点击、停留、互动、发布、关注、举报

## 常见数据风险

- 曝光、点击、播放、阅读的事件定义不一致
- 去重口径不同导致 UV、内容数、创作者数不可比
- 算法实验或流量分桶影响整体趋势解释
- 审核延迟导致发布数和可见内容数出现时间差
- 内容多标签、多话题导致分类重复归因
- 机器人、刷量、爬虫流量污染活跃和互动指标

## 适合配合的 Skill

- `dashboard-reviewer`：审查内容生态看板、创作者看板、推荐效果看板
- `business-root-cause-analysis`：分析 DAU、留存、内容供给、互动异常
- `funnel-analysis`：分析曝光、点击、阅读、互动路径
- `retention-cohort-analysis`：分析用户回访和创作者持续发布
- `data-presentation-architect`：整理内容生态复盘和策略汇报
