# 留存 Cohort 分析上下文模板

用于向 `retention-cohort-analysis` Skill 提供标准化输入，帮助 AI 准确理解你的 Cohort 定义和分析目标。

## 使用方法

复制以下模板，填写你的业务信息，粘贴到对话框中，再激活 `retention-cohort-analysis` Skill。
