# data-analysis-report-writer 示例

## 适用场景

分析结果已经有了，需要写成业务方能读懂、能决策的报告。

## 示例输入

```text
请用 data-analysis-report-writer 写一份转化下降分析报告：

主题：5 月新用户首购转化率下降
读者：业务负责人和产品经理
已知数据：
- 总转化率从 8.2% 降到 6.9%
- 下降主要集中在移动端
- 渠道 A 新用户占比提升，但渠道 A 转化率低于平均
- 支付页加载时间从 1.8s 上升到 3.4s
```

## 预期输出

```markdown
# 5 月新用户首购转化率下降分析

## 执行摘要

5 月新用户首购转化率从 8.2% 降至 6.9%，下降 1.3 个百分点。下降主要集中在移动端，可能与渠道结构变化和支付页性能恶化有关。

## 核心发现

### 发现一：移动端是主要下降来源

- 数据证据：下降集中在移动端。
- 解释判断：移动端用户链路可能存在额外阻力。
- 业务影响：移动端是新用户主要入口时，会放大整体转化损失。

### 发现二：渠道结构变化拉低整体转化

- 数据证据：渠道 A 占比提升，但转化率低于平均。
- 解释判断：新增流量质量可能下降。

## 建议动作

| 优先级 | 建议 | 预期收益 |
| --- | --- | --- |
| P0 | 排查移动端支付页加载性能 | 修复直接转化阻塞 |
| P1 | 拆分渠道 A 的来源和落地页 | 判断是否继续投放 |
```

## 使用说明

分析报告必须把数字翻译成判断和动作。只有数据表，不算报告。
