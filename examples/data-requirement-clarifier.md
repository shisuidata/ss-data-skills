# data-requirement-clarifier 示例

## 适用场景

业务方只提出了一个模糊问题，需要先整理成数据开发或数据分析任务。

## 示例输入

```text
请用 data-requirement-clarifier 帮我澄清这个需求：

业务说最近新用户购买转化下降了，想知道原因。
希望能按渠道和设备拆一下，最好本周五前给结论。
```

## 预期输出

```markdown
## 需求澄清结果

### 一句话目标

判断最近新用户购买转化下降是否真实存在，并定位主要影响渠道、设备和转化环节。

### 需求类型

专题分析 + 异常排查。

### 指标拆解

| 指标 | 含义 | 粒度 | 口径状态 |
| --- | --- | --- | --- |
| 新用户购买转化率 | 新注册用户中完成支付的比例 | 日期 + 渠道 + 设备 | 待确认 |
| 注册用户数 | 统计周期内完成注册的新用户数 | 日期 + 渠道 + 设备 | 待确认 |
| 支付成功用户数 | 注册后指定窗口内完成支付的用户数 | 日期 + 渠道 + 设备 | 待确认 |

### 待确认问题

- “最近”具体指哪段时间？
- 新用户按注册时间还是首次访问时间定义？
- 购买转化窗口是当日、7 日内还是自然周？
- 退款订单是否仍算转化？
```

## 使用说明

这个 Skill 的价值在于先把问题问清楚，避免直接写 SQL 后发现口径和业务目标不一致。
