# retention-cohort-analysis 示例

## 适用场景

想判断不同批次用户后续是否继续活跃、复购或留存。

## 示例输入

```text
请用 retention-cohort-analysis 分析新用户留存：

Cohort 起点：注册日期
留存行为：任意一次打开 App
窗口：D1、D7、D30
维度：渠道、设备、首日是否完成关键行为
```

## 预期输出

```markdown
## 留存 / Cohort 分析结果

### Cohort 定义

| 项目 | 口径 |
| --- | --- |
| Cohort 起点 | 注册日期 |
| 回访行为 | 打开 App |
| 统计对象 | user_id |
| 时间窗口 | D1、D7、D30 |

### 关键发现

- 渠道 A 的 D1 留存不低，但 D7 留存下降明显，可能是低质量拉新或首日激励驱动。
- 首日完成关键行为的用户 D7 留存显著更高，建议把关键行为前置到新手引导。

### 待确认问题

- D1 是注册次日自然日，还是注册后 24-48 小时？
- App 打开事件是否存在后台唤醒误计？
```

## 使用说明

留存分析最容易被时间窗口口径影响。先定义 Cohort，再看矩阵。
