# weekly-monthly-report-writer 示例

## 适用场景

有一堆零散工作事项，需要整理成周报、月报或项目进展。

## 示例输入

```text
请用 weekly-monthly-report-writer 帮我写本周周报：

本周做了：
- 梳理新用户首购转化口径
- 修复渠道看板昨天数据为空的问题
- 和产品确认会员页实验指标
- 写了活动复盘 SQL，但还差退款口径确认
读者：直属 Leader
```

## 预期输出

```markdown
# 本周工作周报

## 本周期重点

本周主要围绕新用户转化分析、渠道看板稳定性和会员页实验口径推进。

## 关键进展

| 方向 | 进展 | 价值/影响 | 状态 |
| --- | --- | --- | --- |
| 指标口径 | 完成新用户首购转化口径梳理 | 支撑后续渠道看板和转化分析 | 已完成 |
| 看板稳定性 | 修复渠道看板分区为空问题 | 避免业务继续基于空数据判断 | 已完成 |
| 实验分析 | 与产品确认会员页实验核心指标 | 为实验复盘建立口径基础 | 已完成 |
| 活动复盘 | 完成主体 SQL，退款口径待确认 | 复盘报告可继续推进 | 进行中 |

## 风险与阻塞

- 活动复盘的退款口径未最终确认，可能影响 GMV 和转化结论。

## 下周期计划

- 完成活动复盘退款口径确认。
- 输出新用户转化分析初版结论。
```

## 使用说明

好的周报不是流水账。它要让读者知道进展、价值、风险和下一步。
