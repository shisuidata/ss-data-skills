# 示例索引

这个目录放脱敏后的 Skill 使用示例。

示例的作用是帮助用户快速理解：

- 什么时候该用这个 Skill
- 应该给 Agent 什么输入
- 大致会得到什么输出
- 输出是否符合自己的工作场景

## 示例规范

每个示例应包含：

- 适用场景
- 示例输入
- 预期输出
- 使用说明

所有示例都必须是脱敏数据，不要提交真实公司、客户、账号、表名、截图或日志。
