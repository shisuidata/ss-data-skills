# funnel-analysis 示例

## 适用场景

想知道用户从一个起点到目标行为之间，具体在哪一步流失。

## 示例输入

```text
请用 funnel-analysis 分析这个新用户首购漏斗：

时间：2026-05-01 到 2026-05-14
对象：user_id 去重
步骤：注册 -> 浏览商品 -> 加购 -> 提交订单 -> 支付成功
维度：渠道、设备
```

## 预期输出

```markdown
## 漏斗分析结果

### 漏斗定义

| 步骤 | 事件/状态 | 统计对象 |
| --- | --- | --- |
| 注册 | register_success | user_id |
| 浏览商品 | product_view | user_id |
| 加购 | add_to_cart | user_id |
| 提交订单 | order_submit | user_id |
| 支付成功 | pay_success | user_id |

### 关键流失点

- 最大单步流失发生在“浏览商品 -> 加购”。
- 移动端流失明显高于桌面端，建议优先排查移动端商品详情页和加购交互。

### 数据风险

- 需要确认事件顺序是否按 event_time 判断。
- 需要确认跨设备用户是否能统一到同一个 user_id。
```

## 使用说明

漏斗分析必须先明确步骤顺序和统计对象，否则转化率没有意义。
