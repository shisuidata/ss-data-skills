# data-viz-kit 示例

## 适用场景

分析已经做完，需要把结论变成一份老板能直接打开、手机上也能看的数据报告页面。

## 示例输入

```text
请用 data-viz-kit 把下面的周度经营数据做成一份 HTML 周报。

受众：电商运营负责人，看完要决定是否调整信息流预算。
核心结论：近 7 日 GMV 同比 −2.6%，下滑集中在工作日和信息流投放渠道。
数据：
- 每日 GMV（5/12–5/25）及去年同期（按星期对齐）
- 各渠道近 14 日 GMV：自然流量 812 万、信息流 655 万、达人带货 402 万、私域 318 万、搜索 236 万
- 各渠道同比及 95% 区间
- 已知数据问题：信息流 5/21 起 UTM 参数变更；搜索广告缺 5/24 花费
```

## 预期输出

Agent 用 `scripts/sskit_viz.py` 生成报告（可参考 `scripts/demo_report.py`，它就是这个例子），然后输出：

```markdown
## 图表交付

- 报告文件：weekly_report.html
- 核心结论：GMV 同比转负，工作日下滑、周末持平，主要来自信息流投放

| 图 | 回答的问题 | 图形 | 为什么选它 |
| --- | --- | --- | --- |
| 结论横幅 | 发生了什么、要不要关注 | callout（warning） | 5 秒内传达结论 |
| 核心指标 | 整体表现如何 | 4 个指标卡 | 关键数字不需要图 |
| 每日 GMV | 下滑发生在哪些天 | 折线图，去年同期用中性灰 | 时间变化；对比序列不抢主线 |
| 渠道 GMV | 哪个渠道体量最大 | 横向条形图，按数值排序 | 中文标签横排易读 |
| 渠道同比 | 哪些渠道的变化是真的 | 区间图 | 同时表达方向、幅度和不确定性 |
| 数据可信度 | 结论能信几分 | 检查清单 | 把 UTM 变更和缺数暴露给读者 |

- 采用的约定：好坏色（墨绿=变好，朱红=变坏），金额用“万”，同比按星期对齐
- 假设与待确认：信息流 5/21 后部分订单可能被归入自然流量，渠道拆分结论偏保守
```

## 使用说明

- 先写结论句再选图；写不出结论的图不要放。
- 不显著的变化用中性灰，不要给噪声上红绿色。
- 受众是证券、交易类业务时，改用红涨绿跌（`delta_tone(..., convention="market")`），并在报告里写明约定。
