# 分析报告写作指南

## 1. 结构：结论先行

读者往往只看第一屏，所以第一屏要能单独成立：

1. **一句话结论**：发生了什么 + 最关键的数字 + 主要在哪里。例如：

   > 4 月试用转付费从 6.9% 降到 5.5%（−1.4pp），下降主要集中在 onboarding 之后的两步和信息流广告用户。

2. **需要的决策**：读者看完要拍板什么。没有决策的报告，读者看完只会说“知道了”。
3. **指标卡**：2~4 个。结论里最关键的数字放第一个。
4. **执行摘要**：3 条以内，每条是“结论 + 一个数字”，不写过程。

后面的核心发现、假设、建议，都是为了支撑这几句话。

## 2. 标题和发现写成结论

| 不好 | 好 |
| --- | --- |
| 漏斗分析 | 下降集中在 onboarding 前后两步，后两步基本持平 |
| 渠道维度分析 | 信息流广告用户变多、且自身转化变差，两件事叠加 |
| 实验结果 | 新版支付页提升不显著，当前样本只能检测 21% 以上的提升 |

每个发现只讲一件事。证据写读者能核对的数字；解释回答“这说明什么”；影响回答“这对业务意味着多少钱、多少用户”。

## 3. 事实、推断、建议分开

| 层次 | 写法 | 例子 |
| --- | --- | --- |
| 事实 | 数据直接显示，必须有引用 | 邀请步骤转化 54.0% → 48.0% |
| 推断 | 对原因的判断，写进“解释”或“原因假设” | 可能与新版邀请流程有关 |
| 建议 | 具体动作 + 负责人 + 时间 | 增长产品经理下周一前对比 4 月 8 日前后的邀请转化 |

## 4. 因果措辞要和证据强度匹配

| 证据 | 可以写 | 不要写 |
| --- | --- | --- |
| 随机实验，显著 | 新版页面使支付成功率提升 3.2%（95% 区间 …） | — |
| 时间重合 + 分群差异 | 下降与新版上线在时间上重合；主要集中在 X 渠道 | 新版导致了下降 |
| 结构拆解 | 约三分之一的下降来自用户构成变化 | 信息流广告造成了下降 |
| 只有相关 | A 高的用户 B 也高 | A 提升了 B |

`build` 会扫描一句话结论、摘要和发现标题里的“导致、造成、使得、归因于、是因为、根本原因”，提醒你检查。

## 5. 建议要能执行

| 空洞 | 可执行 |
| --- | --- |
| 持续关注转化变化 | 数据分析本周三前用服务端邀请记录核对埋点 |
| 优化 onboarding 体验 | 把企业邮箱验证改为可跳过，用 A/B 实验验证，两周后看邀请转化 |
| 加强渠道管理 | 投放负责人停掉 onboarding 完成率最低的 3 个信息流计划 |

建议先写“排除口径风险”的动作（核对埋点、核对口径），再写改产品、调预算的动作。建立在错误数据上的产品改动成本最高。

预期收益尽量从来源算出来。例如“若邀请恢复到 3 月水平，整体转化可回到 6.2%”，用的是漏斗脚本的反事实值。

## 6. 按读者调整

| 读者 | 关心 | 写法 |
| --- | --- | --- |
| CEO / 业务负责人 | 影响多大、要不要拍板 | 一句话结论换算成钱或客户数；建议只留 P0 |
| 产品经理 | 哪一步、哪类用户、怎么验证 | 发现写到步骤和分群；假设配验证方法 |
| 投放 / 运营 | 哪个渠道、哪个计划 | 分群拆解、渠道占比变化 |
| 数据团队 | 口径和可信度 | 风险与限制写全，附录保留数字溯源 |

## 7. 风险与限制要具体

- 写清楚哪个结论受影响，例如“汇总数据无法验证事件顺序，步骤转化可能偏高”，而不是“数据可能有误差”。
- 来源脚本标记的问题（成熟度、SRM、P0 数据问题）会自动出现在“风险与限制”里，不要删。
- 小样本、短周期、节假日、口径变更，都要明说对结论方向的影响。

## 8. 常见错误

- 写成数据罗列：十几个指标没有一句判断
- 数字和来源对不上：手抄时四舍五入不一致，或者把本期和上期抄反
- 把不显著的变化写成“上升 / 下降”。不显著就写“没有显著变化”，指标卡不上色
- 相对变化和百分点混用：比例之间的差用 pp，相对变化用 %
- 结论和建议脱节：发现说是渠道问题，建议却去改产品
- 用一个分群的变化解释整体，却没有说明这个分群占多大比重

## 数字必须能核对

“两成”“翻倍”“近半”这类写法无法和来源比对，`report.py` 会列入 `uncheckable`，`--strict` 不通过。需要这样表达时，写成 `{{rel_drop|abs|pct.0}}` 这样的引用，或把派生数字写进 `facts` 的 `expr`。

## 因果措辞

“导致、造成、由于、因为、引起、源于、带来了、驱动了”等词只用于实验结论或已验证的机制。其余情况写成“与…同时发生”“主要集中在”。
