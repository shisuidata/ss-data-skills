# 常见指标陷阱

这里是审查时的提问清单，不是标准答案。用户公司的口径以业务规则为准，不能把这里的常见做法当成事实。

## 交易类

**GMV**

- 下单金额还是支付金额？是否扣退款、优惠券、运费？
- 退款计入下单日还是退款日？跨月退款是否回冲？
- 取消订单、测试订单、内部购买是否排除？

**客单价**

- 分母是订单数还是支付用户数？两者是不同指标。
- 均值被少数大单拉高时，看中位数和分布。

**退款率**

- 分母是当期支付订单还是当期退款对应的历史订单？
- 部分退款算一单还是按金额？

## 用户类

**DAU / MAU**

- 什么行为算活跃？打开、登录还是核心行为？
- 推送到达和后台唤醒要排除。
- 多端用户如何去重？未登录设备算不算？

**新增用户**

- 注册、首次打开还是首次核心行为？
- 卸载重装、换设备是否算新增？

## 转化类

**转化率**

- 分母是访问用户、注册用户还是到达上一步的用户？
- 转化窗口多长？窗口未走完的用户要排除，否则低估。
- 按入口时间还是转化时间归属？两者结果不同。

## 留存类

**次日、7 日留存**

- 自然日还是滚动 24 小时？
- 第 N 日当天回访，还是 N 日内回访？
- 回访行为是否排除了被动事件？
- 未成熟的批次不能和成熟批次比较。

**复购率**

- 观察窗口多长？新客和老客分开看。
- 同一天多笔订单算一次还是多次？

## SaaS 类

**MRR / ARR**

- 年付如何分摊？一次性费用不计入。
- 试用、赠送、合同已签未生效如何处理？

**NRR**

- 期初客户固定，排除新签。
- 升级计入，降级和流失扣减。
- 部分取消仍有席位时，按金额变化计算。

**Churn**

- 按客户数还是金额？两者差异可能很大。
- 分母是期初客户，不是当前客户。
- 到期未续和主动取消分别统计。

## 比率指标通用

- 分子分母的时间范围、过滤条件要一致。
- 比率的平均值不等于汇总后的比率。
- 分母很小的分组不做排名。
