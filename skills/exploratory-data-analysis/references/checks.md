# 检查项说明

`scripts/eda.py` 的每项检查、判定规则和分级。分级含义：

- **P0**：不处理就会算错（数据被放大、字段错位、关联丢数）
- **P1**：需要在分析口径里显式处理，否则结论有偏
- **P2**：了解即可，或只影响部分分析

## 文件层

| 检查 | 规则 | 级别 |
| --- | --- | --- |
| 编码 | 先按 UTF-8 解码，失败再按 GB18030（兼容 GBK）。Excel 另存的中文 CSV 常是 GBK | P2 |
| 分隔符 | 自动识别逗号、Tab、分号、竖线 | — |
| 列数错位 | 某行列数和表头不同，常见于备注、地址里有未转义的逗号或换行 | P0 |
| 抽样 | 用了 `--max-rows` 时提示只体检了部分数据 | P2 |

## 表层

| 检查 | 规则 | 级别 |
| --- | --- | --- |
| 主键 | 指定 `--key` 时检查重复和空值；未指定时列出单列唯一键候选 | 重复 P0；无候选 P1 |
| 完全重复行 | 所有列都相同的行 | P1 |
| 分区与事件时间 | 表里有 `dt` / `ds` / `pt` 等分区列和事件时间列时，比较两者日期是否一致；不一致通常是晚到数据 | 超过 1% 为 P1 |
| 日期断档 | 按时间字段统计每日行数，找出 0 行的日期；数据稀疏（日均不足 5 行）时不报 | P1 |
| 数据量突增突降 | 每日行数相对中位数的稳健 z（中位数绝对偏差）> 5 | P2 |
| 高相关数值列 | Pearson \|r\| ≥ 0.95，可能是同一信息的两种表示 | P2 |

占位日期（1970 年、2099 年、2000 年前的 1 月 1 日）和未来时间不参与趋势和分区检查，否则会把时间范围拉长几十年。

## 字段层

| 检查 | 规则 | 级别 |
| --- | --- | --- |
| 类型推断 | 布尔、整数、数值、文本型数字、时间（含 10 / 13 位时间戳）、ID、类别、字符串、长文本 | — |
| 缺失率 | 空字符串 + 明确的空值占位（`NULL`、`\N`、`NaN`、`N/A`、`0000-00-00` 等）；超过 30% | P1 |
| 伪缺失 | 上面这些占位值的出现次数。Hive 导出的 `\N` 最常见 | P1 |
| 疑似占位值 | `none`、`-`、`未知`、`无`、`其他`、`unknown` 等：可能是缺失，也可能是业务取值（如 `refund_status=none`），只提示不计入缺失率 | P2 |
| 文本型数字 | `￥1,234.50`、`12.5%`、`3万` 等带格式的数字 | P1 |
| 混合类型 | 5%~98% 的取值是数字，其余是文本 | P1 |
| 无法解析的值 | 数值或时间列里解析失败的取值 | P1 |
| 前导零 | 纯数字 ID 以 0 开头，按数字读取会丢失 | P1 |
| 超长数字 ID | 16 位以上，经过 Excel 会被截断成科学计数法 | P1 |
| 多种写法 | 忽略大小写、空格、下划线、短横线后相同的取值（iOS / ios / IOS） | P2 |
| 首尾空格 | 看起来相同但关联不上 | P2 |
| 未来时间 | 晚于当前时间一天以上 | P1 |
| 占位日期 | 1970 年、2099 年、2000 年前的 1 月 1 日 | P1 |
| 极端值 | 超出 [P25 − 3×IQR, P75 + 3×IQR] 且占比 > 0.1% | P2 |
| 金额负值 | 字段名含 amount / price / gmv / fee / cost / 金额 / 价格 时的负值 | P2 |
| 常量列 | 只有一个取值 | P2 |
| 整列为空 | — | P1 |

## 关联层（`--join 子表.列=主表.列`）

| 检查 | 规则 | 级别 |
| --- | --- | --- |
| 孤儿键 | 子表中在主表找不到的键；比例 > 5% 为 P0，否则 P1 | P0 / P1 |
| 主表键不唯一 | 关联后会放大数据 | P0 |
| 主表无子记录 | 例如没有下过单的用户数，作为参考 | — |
| 单键最多子记录 | 例如一个用户最多几笔订单，异常大时检查是否有测试账号 | — |

## 脚本不做的事

- 不判断字段的业务含义，也不判断异常是不是“真的”。负金额、突增、长尾都可能是真实业务。
- 不做因果推断。
- 不替代长期质量监控。需要上线监控时，把体检发现的问题交给 `data-quality-rule-generator`。

## Excel 导出常见问题

| 检查项 | 级别 | 说明 |
| --- | --- | --- |
| 科学计数法 ID | P0 或 P1 | `1.23E+17` 这类写法说明超过 15 位的数字已被 Excel 截断，后几位不可恢复。回到源系统按文本重新导出 |
| Excel 序列日期 | P1 | 日期列里是 45000 这样的数字，按 1899-12-30 为基准换算 |
| 公式错误值 | P1 | `#REF!`、`#DIV/0!`、`#VALUE!` 等，计入伪缺失。原始值已丢失，要回源表修复 |
| 多种日期写法 | P1 | 同一列混有 `2026-05-01`、`2026/05/02`、`5月3日` 等写法，缺年份的写法要先确认年份 |

xlsx 文件直接读取，日期格式的单元格会自动转成日期。旧版 `.xls` 需要先另存为 `.xlsx` 或 CSV。

## 抽样

`--max-rows` 在全表上随机抽样，种子固定，结果可复现。分布和趋势基本可信，但重复键和孤儿键会被低估，这两项建议全量检查。
