# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `eda.py profile`

对一张或多张表做体检

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--table`（可重复） | 否 | — | 表名=CSV、TSV 或 xlsx 路径，可重复 |
| `--sheet`（可重复） | 否 | — | 表名=工作表名，只对 xlsx 有效，默认第一个工作表 |
| `--tz` | 否 | +08:00 | 业务时区，带时区的时间会换算到这里，默认 +08:00 |
| `--key`（可重复） | 否 | — | 表名=主键列，组合主键用 + 连接，如 orders=order_id 或 events=user_id+event_time |
| `--join`（可重复） | 否 | — | 关联检查：子表.列=主表.列，如 orders.user_id=users.user_id |
| `--time-col`（可重复） | 否 | — | 表名=时间列，用于趋势和分区一致性检查；默认自动选择 |
| `--max-rows` | 否 | — | 每张表最多体检的行数，在全表上随机抽样（结果会注明） |
| `--html` | 否 | — | 输出 HTML 报告路径 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
