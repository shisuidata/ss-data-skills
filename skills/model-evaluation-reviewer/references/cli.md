# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `eval_metrics.py classify`

二分类：AUC、PR-AUC、Top-K、校准、阈值收益、基线对比

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | 预测结果 CSV，一行一个样本 |
| `--label` | 是 | — | 真实标签列 |
| `--score` | 是 | — | 模型分数列 |
| `--baseline-col` | 否 | — | 基线模型分数列 |
| `--top` | 否 | 0.05,0.1,0.2,0.3 | Top-K 覆盖比例，逗号分隔 |
| `--threshold` | 否 | — | 评估某个固定阈值 |
| `--benefit-tp` | 否 | — | 命中一个正样本的收益 |
| `--cost-fp` | 否 | — | 误判一个负样本的成本 |
| `--time-col` | 否 | — | 时间列，用于检查不同时期的稳定性 |
| `--time-unit` | 否 | month | 可选：week、month |
| `--bootstrap` | 否 | 200 | Bootstrap 次数，0 表示跳过 |
| `--seed` | 否 | 42 | — |
| `--name` | 否 | — | 报告标题 |
| `--html` | 否 | — | 输出 HTML 报告路径 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |

## `eval_metrics.py regress`

回归：RMSE、MAE、MAPE、偏差、R²

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | — |
| `--y` | 是 | — | 真实值列 |
| `--pred` | 是 | — | 预测值列 |
| `--baseline-col` | 否 | — | 基线预测列 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |

## `eval_metrics.py rank`

排序或推荐：NDCG@K、MRR、Recall@K

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | — |
| `--query` | 是 | — | 查询或用户列 |
| `--relevance` | 是 | — | 相关度列，0 表示不相关 |
| `--score` | 是 | — | 排序分数列 |
| `--k` | 否 | 10 | — |
| `--json` | 否 | — | 同时把 JSON 写入文件 |

## `eval_metrics.py psi`

分布漂移：训练集和线上数据的 PSI

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--base` | 是 | — | 基准数据 CSV |
| `--current` | 是 | — | 当前数据 CSV |
| `--col` | 是 | — | 要比较的列 |
| `--bins` | 否 | 10 | — |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
