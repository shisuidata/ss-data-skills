# 拾穗配色

所有取值定义在 `scripts/sskit_viz.py` 的 `THEMES` 中，HTML 里通过 CSS 变量引用（`var(--series-1)`、`var(--good)` 等），亮暗模式自动切换。

改任何颜色后运行：

```bash
python3 scripts/check_palette.py
```

## 设计来源

底色取自拾穗品牌的暖纸色，强调色是麦穗金。数据颜色在品牌调性内重新取值，并逐对做了色觉障碍模拟校验。

## 分类色（表示“是哪一个”）

按固定顺序使用，**不要循环、不要跳着用**。第 8 个序列不生成新颜色，归入“其他”或拆成小多图。

| 序号 | 色名 | 亮色模式 | 暗色模式 |
| --- | --- | --- | --- |
| 1 | 墨蓝 | `#2f6bb3` | `#5b8fd6` |
| 2 | 麦金 | `#c99a3d` | `#d4ad5a` |
| 3 | 青绿 | `#2a9d8f` | `#38b49a` |
| 4 | 赭红 | `#c8553d` | `#e07a62` |
| 5 | 紫 | `#7b61b8` | `#9d86de` |
| 6 | 草绿 | `#5b8c3a` | `#7fb15a` |
| 7 | 粉 | `#d0739a` | `#e592b4` |

校验结果（相邻色）：色觉障碍模拟 ΔE 最低值亮色 11.0、暗色 8.4，均高于 8 的目标；正常视觉 ΔE 最低值亮色 19.2、暗色 17.6，均高于 15 的下限。散点、地图等所有颜色互相相邻的图形，最多用前 3 个颜色（前 3 色两两组合在亮暗模式下均通过校验）。亮色模式下麦金对比度 2.49，低于 3:1，使用时必须配直接标签或表格。

对照组、基准线、“去年同期”等不需要强调的序列用中性灰 `var(--neutral)`，不占分类色。

## 状态色（表示“好不好”）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| good | `#1b7f79` 墨绿 | 显著变好、检查通过 |
| warning | `#d9a21b` 琥珀 | 需要注意、结论待定 |
| bad | `#d1453b` 朱红 | 显著变坏、检查不通过 |
| neutral | `#8c8578` 暖灰 | 不显著、无变化 |

状态色亮暗模式共用。墨绿和朱红在色觉障碍模拟下 ΔE 为 9.8：刻意选了偏青的绿，因为纯绿与红在红绿色弱下几乎无法区分。即便如此，状态色**永远配图标和文字**，不单独表达含义。

文字使用专门的加深色（`--good-text`、`--bad-text`、`--warning-text`），不直接用图形色写字。

## 顺序与发散

- 顺序数据（热力表、留存矩阵）：用墨蓝单色从浅到深，最浅一级接近底色表示“接近 0”。
- 发散数据（同比正负、偏离目标）：墨绿 ↔ 中性灰 ↔ 朱红，或墨蓝 ↔ 灰 ↔ 赭红；中点必须是灰色。
