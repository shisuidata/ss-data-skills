# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `decompose.py confirm`

判断异常是否真实：和同星期历史窗口比较

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | 日粒度 CSV |
| `--date-col` | 否 | dt | — |
| `--value-col` | 是 | — | — |
| `--start` | 是 | — | 异常窗口开始日期 |
| `--end` | 是 | — | 异常窗口结束日期（含） |
| `--history-windows` | 否 | 8 | 向前取多少个同星期窗口，默认 8 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |

## `decompose.py factors`

把乘法公式的指标变化拆到各因子（LMDI）

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--factor`（可重复） | 是 | — | 名称=基期,当期，可重复 |
| `--target` | 否 | 目标指标 | 目标指标名称 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |

## `decompose.py dimensions`

按维度排序变化贡献，比率指标拆成结构效应和转化效应

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | 按时期和维度汇总的 CSV |
| `--period-col` | 否 | period | — |
| `--base` | 是 | — | 基期取值 |
| `--current` | 是 | — | 当期取值 |
| `--dim`（可重复） | 是 | — | 维度列，可重复 |
| `--metric` | 否 | — | 可加指标列，如 gmv |
| `--numerator` | 否 | — | 比率指标的分子列 |
| `--denominator` | 否 | — | 比率指标的分母列 |
| `--name` | 否 | — | 报告标题 |
| `--html` | 否 | — | 输出 HTML 报告路径 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
