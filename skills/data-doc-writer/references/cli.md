# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `doc_gen.py draft`

生成文档草稿

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--ddl` | 否 | — | CREATE TABLE 语句文件 |
| `--sql` | 否 | — | 生产这张表的 SQL 文件，用于提取上游 |
| `--eda` | 否 | — | eda.py 的 JSON 输出 |
| `--eda-table` | 否 | — | --eda 中要使用的表名 |
| `--format` | 否 | md | 输出格式。可选：md、yaml、dbt |
| `--out` | 否 | — | 输出文件路径 |
