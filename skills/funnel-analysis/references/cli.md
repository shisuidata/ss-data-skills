# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `funnel.py analyze`

计算漏斗并生成报告

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--summary` | 否 | — | 汇总数据 JSON（见 references/input-schema.md） |
| `--events` | 否 | — | 事件明细 CSV，每行一个事件 |
| `--user-col` | 否 | user_id | — |
| `--event-col` | 否 | event_name | — |
| `--time-col` | 否 | event_time | — |
| `--tz` | 否 | +08:00 | 业务时区，带时区的时间会换算到这里，默认 +08:00 |
| `--step`（可重复） | 否 | — | 步骤：名称=事件名，多个事件用 \| 分隔；按漏斗顺序重复填写 |
| `--users` | 否 | — | 用户属性 CSV（用于分群），按 --user-col 关联 |
| `--segment`（可重复） | 否 | — | 分群列；有 --users 时取用户属性，否则取入口事件所在行 |
| `--period`（可重复） | 否 | — | 时期：名称=YYYY-MM-DD..YYYY-MM-DD，按入口时间划分 |
| `--baseline` | 否 | — | 作为对比基准的时期名称 |
| `--window-days` | 否 | — | 转化窗口：入口后 N 天内完成才算转化；未走完窗口的用户会被排除 |
| `--name` | 否 | — | 报告标题 |
| `--html` | 否 | — | 输出 HTML 报告路径 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
