# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `sql_lint.py check`

检查一个或多个 SQL 文件

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--sql`（可重复） | 是 | — | SQL 文件路径，可重复 |
| `--dialect` | 否 | generic | 执行引擎，影响整数除法等规则。可选：DIALECTS |
| `--partition-col`（可重复） | 否 | — | 分区字段，可重复；不填时只在 SQL 已使用常见分区字段时检查 |
| `--fail-on` | 否 | — | 存在该级别及以上问题时返回非 0，便于接入 CI。可选：P0、P1、P2 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
