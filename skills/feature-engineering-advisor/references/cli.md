# 命令行参数

这份文档由脚本的参数定义生成，修改参数后请重新生成，不要手改。所有脚本都把结果以 JSON 打印到标准输出。

## `leakage_check.py check`

检查特征表

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--csv` | 是 | — | 特征表 CSV，一行一个样本 |
| `--label` | 是 | — | 标签列 |
| `--asof-col` | 否 | — | 预测时间点列 |
| `--feature-time`（可重复） | 否 | — | 特征=该特征的生成时间列，可重复 |
| `--exclude`（可重复） | 否 | — | 不参与检查的列，如 ID |
| `--tz` | 否 | +08:00 | 业务时区，默认 +08:00 |
| `--json` | 否 | — | 同时把 JSON 写入文件 |
