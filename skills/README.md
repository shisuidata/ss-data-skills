# 技能目录

这个目录收录面向数据从业者日常工作的 Skill。每个子目录对应一个可以单独使用的工作技能，核心说明都在对应目录的 `SKILL.md` 中。

当前技能覆盖几类场景：

- 数据开发与治理：需求、指标、表设计、SQL、质量规则、血缘影响、工具接入
- 数据分析与业务判断：EDA、漏斗、留存、实验、看板、业务归因、市场调研
- 表达、协作与复盘：日报、周报月报、分析报告、PPT 大纲、数据文档、事故复盘

## 如何查找

如果你还不清楚 Skill 的原理，先看 [Skill 入门教程](../docs/skill-tutorial.md)。

如果你已经知道要处理的工作，可以直接从 [技能索引](../SKILL_INDEX.md) 选择。

如果你想先看具体输入输出，可以从 [示例索引](../examples/README.md) 开始。

如果你准备把技能用到真实工作里，建议同时阅读 [上下文使用指南](../CONTEXT_GUIDE.md) 和 [上下文模板](../context/README.md)。

## 如何使用

1. 打开目标技能目录。
2. 阅读 `SKILL.md` 中的适用场景、输入信息、工作流程和输出格式。
3. 复制示例 Prompt，并补充自己的业务背景、数据材料和输出要求。
4. 如果任务比较复杂，再补充上下文模板或行业上下文包。

每个技能都尽量保持独立：信息充分时给出明确结论，信息不足时列出假设和待确认问题，避免凭空补全业务规则或数据结构。
